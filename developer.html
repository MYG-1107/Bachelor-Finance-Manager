Project Genesis & Engineering Overview

Bachelors Finance Manager was conceived and developed to eliminate the friction, ambiguity, and communication overhead associated with shared financial obligations in student and bachelor flat accommodations. In typical shared living situations, multiple members incur recurring variable expenses across categories such as room rent, electricity bills, groceries, LPG cylinders, and internet services.

The system implements a deterministic Greedy Debt Settlement Graph Algorithm to calculate the global minimum number of interpersonal transactions necessary to completely balance the shared pool.

Technology Stack & Technical Decisions

HTML5 Semantic Core

Zero runtime overhead with standards-compliant DOM hierarchy for high performance on any device.

UDI / NAV Design System

Strict 3-color palette (Red, Black, White) with high-contrast borders and sharp typography inspired by Norwegian public portals.

CSS Paged Media Print Engine

Native browser-level `@media print` layout formatting that prints directly to standard A4 PDF files without third-party server-side dependencies.

Deterministic Debt Resolution

Greedy settlement algorithm with cent-accurate rounding that reduces O(N²) mutual peer-to-peer debts to a simplified O(N) cash flow sequence.

Browser Storage Persistence

Zero-telemetry client-side storage via the LocalStorage API, guaranteeing total data ownership and privacy.

GitHub Pages Architecture

Stateless, static hosting architecture allowing instant, free deployment with continuous availability.
