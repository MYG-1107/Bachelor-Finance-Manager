PRIVACY

How your workspace data is handled

This static application is designed as a local-first tool. It does not require an account or a backend database for everyday operation.

Where data is stored

Workspace data is stored in your browser's localStorage on the device where you use the app. The application uses that storage to remember workspaces, roommates and expenses.

What this means

No account required

There is no login or password system in this static version.

No cloud sync

Workspace records are not sent to an application server by the app code.

Backups matter

Clearing browser storage, removing site data or losing the device can remove local records. Export a JSON backup for important data.

Security note

Browser local storage is not encrypted secure storage. Do not treat this project as a bank, accounting system or regulated financial records platform.

Third-party assets

The production pages do not require a third-party font CDN or runtime JavaScript library. The application can therefore operate without pulling UI code from an external dependency.
