PRIVACY

How your workspace data is handled

This is a static, local-first browser application. It does not require an account or an application backend for everyday operation.

Where data is stored

Workspace data is stored in the browser's localStorage for this website origin and browser profile. The app uses it to remember workspaces, roommate names and expenses on this device/profile.

What the application does

No account required

There is no login, password system or authenticated user identity in this static version.

No application data sync

The app code does not send workspace records to an application server. There is no cloud database or multi-device synchronization.

Browser-based files

JSON import is read in the browser. CSV and JSON exports are generated as local downloads using browser APIs.

What this does not guarantee

Browser localStorage is not encrypted secure storage. Other scripts running with the same site origin and anyone with access to the same unlocked browser profile may be able to access the data. The hosting provider still serves the website files and receives normal browser requests for those files; that is separate from the application sending workspace records to a backend.

Backups and data loss

Clearing browser storage, deleting site data, losing the browser profile or losing the device can remove local records. JSON backup exports the complete active workspace only, not all saved workspaces. Store backup files carefully because they may contain names and household spending details.

Security scope

This project is a household expense-sharing aid, not a bank, payment processor, tax service or regulated accounting system. Suggested transfers are calculations only; the application does not move money or verify that a payment occurred.

Third-party runtime code

The application pages use local project assets and native browser JavaScript. They do not require an external font CDN or third-party JavaScript library to run.
